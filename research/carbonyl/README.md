# Formaldehyde hydride-addition electronic structures

Explicit idealized system: isolated gas-phase H− + H2CO → CH3O−, charge −1,
singlet, 18 electrons. This models the existing carbonyl-addition event, not a
complete LiAlH4/NaBH4 reduction or work-up. The existing candidate 1113 code stays.

Use Python 3.12 with pinned `requirements.txt`, then:

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python research/carbonyl/compute.py
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python research/carbonyl/fields.py
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python research/carbonyl/analyze.py
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python research/carbonyl/detachment.py
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python research/carbonyl/validate.py
python build_reaction_systems.py
```

The complex uses RHF/6-31++G(d,p), including diffuse hydrogen functions. Four
C–H(nu) distances at 110° relax the four remaining Cs internal parameters. A
separate methoxide geometry relaxes all six Cs parameters and is checked using
the full Cartesian gradient and analytic Hessian (all nine vibrational modes).
Two angle branches at the common 1.9 Å distance use 90° and 130°. These are not
IRC points, a transition state search, an optimal trajectory, or proof of a
universal attack angle. Product minimum validation does not prove the addition
branch is kinetically preferred to H abstraction, electron detachment or other
states. No solution, counterion, metal aggregation, free energy or correlation
claim is made.

Every geometry has coordinates, raw SCF output, float64 wavefunction/density
matrix, phase-aligned coefficients, float32 fixed-grid densities/amplitudes and
explicit precomputed mesh thresholds. Same-frame Hnu− and neutral H2CO fragment
references are retained in their own bases, with no ghosts. Fragment RHF
instabilities are recorded, not silently called ground-state references.

Read `SCHEMA.md` and `V036_AUDIT.md` for references, normalization, tracking,
bond-order conventions, actual validation results and limitations. Existing SN2
wavefunctions, grids and metadata are not regenerated by these scripts.

The isolated RHF hydride binding diagnostic is negative at this level. Thus this
is a constrained finite-basis closed-shell branch demonstration, not a verified
physical gas-phase ground-state pathway. See the conspicuous model-limit notice.
